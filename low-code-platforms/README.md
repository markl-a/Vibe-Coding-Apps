# Low-Code Platforms

This directory contains low-code and no-code platform implementations.

## Categories

### form-builders
Dynamic form generation and builder tools.

### workflow-engines
Visual workflow design and automation engines.

### visual-editors
Drag-and-drop visual development environments.

### app-generators
Application scaffolding and code generation tools.

### integration-platforms
Integration platform as a service (iPaaS) implementations.

## Technology Stack
- **Frontend**: React, Vue, Angular with drag-and-drop libraries
- **Backend**: Node.js, Python, Go
- **Databases**: PostgreSQL, MongoDB, Redis
- **Standards**: JSON Schema, OpenAPI, BPMN
