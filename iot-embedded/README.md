# IoT & Embedded Systems

This directory contains Internet of Things (IoT) and embedded systems projects.

## Categories

### smart-home
Smart home automation systems, device integrations, and home assistant applications.

### wearables
Wearable device applications including smartwatches, fitness trackers, and health monitors.

### industrial-iot
Industrial IoT solutions for manufacturing, monitoring, and process automation.

### sensor-networks
Sensor network implementations, data collection systems, and environmental monitoring.

### edge-devices
Edge device firmware and applications for local processing and connectivity.

## Technology Stack
- **Protocols**: MQTT, CoAP, Zigbee, Z-Wave, BLE, LoRa
- **Platforms**: Arduino, ESP32, Raspberry Pi, STM32
- **Cloud**: AWS IoT, Azure IoT Hub, Google Cloud IoT
- **Languages**: C, C++, Python, Rust, MicroPython
