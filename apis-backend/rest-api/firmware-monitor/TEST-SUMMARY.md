## 測試覆蓋範圍

### 功能覆蓋

- ✅ **設備監控** - 完整的 CRUD 操作和狀態管理
- ✅ **狀態報告** - 數據收集、查詢和統計分析
- ✅ **告警處理** - 自動創建、確認、解決告警
- ✅ **用戶認證** - 註冊、登入、JWT 驗證
- ✅ **數據過濾** - 按狀態、類型、時間範圍等過濾
- ✅ **分頁支持** - 所有列表 API 都支持分頁
- ✅ **統計分析** - 設備和告警的統計數據
- ✅ **權限控制** - 用戶只能訪問自己的資源
- ✅ **錯誤處理** - 完整的錯誤場景測試

### Mock 策略

- ✅ **數據庫隔離** - 使用測試數據庫，每個測試後清理
- ✅ **數據庫連接 Mock** - 使用 `jest.mock()` 模擬數據庫連接
- ✅ **環境變數設置** - 在 `jest.setup.js` 中配置測試環境
- ✅ **獨立測試** - 每個測試用例相互獨立，可單獨運行

### 自動告警測試

測試覆蓋了自動告警機制：

- ✅ CPU 使用率超過閾值（80% 警告，90% 嚴重）
- ✅ 記憶體使用率超過閾值（85% 警告，95% 嚴重）
- ✅ 溫度超過閾值（75°C 警告，85°C 嚴重）
- ✅ 告警正確關聯到設備
- ✅ 告警嚴重程度正確分類

# 運行所有測試

npm test -- --coverage
