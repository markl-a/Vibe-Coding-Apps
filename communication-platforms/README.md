# Communication Platforms

This directory contains communication and collaboration platform projects.

## Categories

### messaging-apps
Real-time messaging and chat applications.

### video-conferencing
Video conferencing and virtual meeting platforms.

### real-time-collaboration
Real-time collaboration tools and shared workspaces.

### notification-systems
Push notification and alert delivery systems.

### webrtc-apps
WebRTC-based communication applications.

## Technology Stack
- **Protocols**: WebRTC, WebSocket, XMPP, Matrix
- **Streaming**: SFU (Selective Forwarding Unit), MCU
- **Backend**: Node.js, Go, Elixir
- **Frontend**: React, Vue, Flutter
