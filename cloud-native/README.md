# Cloud Native

This directory contains cloud-native applications and microservices architectures.

## Categories

### kubernetes-apps
Kubernetes-native applications and operators.

### serverless-apps
Serverless functions and FaaS implementations.

### service-mesh
Service mesh configurations and sidecar implementations.

### cloud-functions
Cloud function implementations across different providers.

### multi-cloud
Multi-cloud and hybrid cloud solutions.

## Technology Stack
- **Orchestration**: Kubernetes, Nomad, Docker Swarm
- **Serverless**: AWS Lambda, Azure Functions, Google Cloud Functions
- **Service Mesh**: Istio, Linkerd, Consul Connect
- **Languages**: Go, Rust, TypeScript, Python
