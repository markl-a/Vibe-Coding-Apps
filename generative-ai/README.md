# Generative AI

This directory contains generative AI and large language model (LLM) applications.

## Categories

### llm-apps
Applications built on large language models.

### rag-systems
Retrieval-Augmented Generation (RAG) implementations.

### ai-agents
Autonomous AI agents and multi-agent systems.

### prompt-engineering
Prompt engineering tools and optimization frameworks.

### multimodal-ai
Multimodal AI applications combining text, image, audio, and video.

### fine-tuning
Model fine-tuning pipelines and training infrastructure.

## Technology Stack
- **LLMs**: OpenAI, Anthropic Claude, Llama, Mistral
- **Frameworks**: LangChain, LlamaIndex, Semantic Kernel
- **Vector DBs**: Pinecone, Weaviate, Chroma, Milvus
- **Training**: Hugging Face, LoRA, QLoRA, PEFT
