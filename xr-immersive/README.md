# XR & Immersive Technologies

This directory contains Augmented Reality (AR), Virtual Reality (VR), Mixed Reality (MR), and immersive experience projects.

## Categories

### ar-apps
Augmented reality applications for mobile and wearable devices.

### vr-apps
Virtual reality experiences and applications for VR headsets.

### mr-apps
Mixed reality applications combining physical and digital worlds.

### 3d-visualization
3D visualization tools, viewers, and rendering applications.

### spatial-computing
Spatial computing applications leveraging environment understanding and interaction.

## Technology Stack
- **Engines**: Unity, Unreal Engine, A-Frame, Three.js
- **SDKs**: ARKit, ARCore, WebXR, OpenXR
- **Devices**: Meta Quest, Apple Vision Pro, HoloLens, Magic Leap
- **Languages**: C#, C++, JavaScript, TypeScript
