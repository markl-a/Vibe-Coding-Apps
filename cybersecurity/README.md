# Cybersecurity

This directory contains cybersecurity tools, security testing, and defensive security projects.

## Categories

### security-tools
General security utilities and helper tools for security professionals.

### vulnerability-scanner
Vulnerability scanning and assessment tools for applications and infrastructure.

### encryption-tools
Encryption, decryption, and cryptographic utility applications.

### auth-systems
Authentication and authorization systems, SSO, MFA implementations.

### threat-detection
Threat detection, intrusion detection, and security monitoring systems.

## Technology Stack
- **Languages**: Python, Go, Rust, C
- **Frameworks**: OWASP, NIST, MITRE ATT&CK
- **Tools**: OpenSSL, Hashicorp Vault, Keycloak
- **Standards**: OAuth2, OIDC, SAML, JWT
