# EdTech

This directory contains educational technology projects.

## Categories

### lms-platforms
Learning Management System implementations.

### e-learning
E-learning platforms and content delivery systems.

### assessment-tools
Assessment, quiz, and examination systems.

### interactive-courses
Interactive course builders and content authoring tools.

### tutoring-systems
Intelligent tutoring systems and adaptive learning.

## Technology Stack
- **Standards**: SCORM, xAPI, LTI, QTI
- **Platforms**: React, Next.js, Vue
- **Video**: WebRTC, HLS, DASH
- **AI**: Adaptive learning algorithms, NLP for feedback
