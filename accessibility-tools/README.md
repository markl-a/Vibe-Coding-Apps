# Accessibility Tools

This directory contains accessibility and assistive technology projects.

## Categories

### screen-readers
Screen reader implementations and enhancements.

### assistive-tech
Assistive technology tools for various disabilities.

### adaptive-interfaces
Adaptive user interfaces that adjust to user needs.

### accessibility-testing
Automated accessibility testing and auditing tools.

## Technology Stack
- **Standards**: WCAG 2.1, ARIA, Section 508
- **Testing**: axe-core, Pa11y, Lighthouse
- **Frameworks**: React Aria, Radix UI, Headless UI
- **Languages**: JavaScript, TypeScript, Python
