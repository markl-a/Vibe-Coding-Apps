# Voice Assistant

This directory contains voice assistant and speech processing projects.

## Categories

### speech-recognition
Automatic Speech Recognition (ASR) systems and implementations.

### text-to-speech
Text-to-Speech (TTS) synthesis and voice generation.

### voice-commands
Voice command interfaces and natural language understanding.

### conversational-ai
Conversational AI systems with voice interfaces.

### audio-processing
Audio processing utilities for voice applications.

## Technology Stack
- **ASR**: Whisper, DeepSpeech, Vosk, Azure Speech
- **TTS**: Coqui TTS, VITS, Tacotron, Amazon Polly
- **NLU**: Rasa, Dialogflow, Amazon Lex
- **Audio**: librosa, PyAudio, Web Audio API
