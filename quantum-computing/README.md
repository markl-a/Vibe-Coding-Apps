# Quantum Computing

This directory contains quantum computing algorithms and simulations.

## Categories

### quantum-algorithms
Quantum algorithm implementations and optimizations.

### quantum-simulation
Quantum system simulations and emulators.

### quantum-ml
Quantum machine learning implementations.

### quantum-cryptography
Quantum cryptography and post-quantum security.

## Technology Stack
- **SDKs**: Qiskit, Cirq, PennyLane, Q#
- **Simulators**: Qiskit Aer, QuTiP, ProjectQ
- **Hardware**: IBM Quantum, Google Sycamore, IonQ, Rigetti
- **Languages**: Python, Q#, Julia
