# Testing & Quality

This directory contains testing automation and quality assurance projects.

## Categories

### test-automation
Automated testing frameworks and tools.

### performance-testing
Performance and load testing solutions.

### api-testing
API testing and contract testing tools.

### visual-regression
Visual regression testing implementations.

### chaos-engineering
Chaos engineering tools for resilience testing.

## Technology Stack
- **Unit Testing**: Jest, Vitest, pytest, JUnit
- **E2E Testing**: Playwright, Cypress, Selenium
- **Performance**: k6, Locust, Artillery, Gatling
- **Chaos**: Chaos Monkey, Litmus, Gremlin
