# Edge Computing

This directory contains edge computing and distributed inference projects.

## Categories

### edge-ai
AI inference at the edge for real-time processing.

### edge-analytics
Edge-based analytics and data processing systems.

### distributed-inference
Distributed ML inference across edge devices.

### on-device-ml
On-device machine learning implementations.

### fog-computing
Fog computing architectures bridging cloud and edge.

## Technology Stack
- **Hardware**: NVIDIA Jetson, Intel Neural Compute Stick, Google Coral
- **Frameworks**: TensorFlow Lite, ONNX Runtime, OpenVINO
- **Platforms**: AWS Greengrass, Azure IoT Edge, KubeEdge
- **Languages**: C++, Python, Rust
